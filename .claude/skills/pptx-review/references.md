# 参考資料（厳選リスト）

/pptx-review が修正案を作るときに最優先で参照する、実在の公開資料と資料作成ガイドの一覧。
初回の /pptx-review 実行時に候補が提示され、選んだものがここに追記される。手で追加・削除してもよい。

- 載せるのは、公式サイトなどで実物を確認できたものだけ（官公庁・企業の公開資料、IR資料、デザインシステムや資料作成ガイド）。
- テンプレート配布サイト、Dribbble 等のコンセプト作品、AI生成のショーケースは載せない。

## 書式

```
## <資料・ガイドの名前>
- URL: <...>
- 種類: <公開資料 / IR資料 / 資料作成ガイド など>
- 参考にする点: <何をどう処理しているか。1〜3行>
- 追加日: YYYY-MM-DD
```

## 伝わるデザイン「レイアウト」「箇条書きと段落」
- URL: https://tsutawarudesign.com/miyasuku4.html （箇条書き: https://tsutawarudesign.com/yomiyasuku5.html ）
- 種類: 資料作成ガイド
- 参考にする点: 余白は本文の1〜2文字分、少なくとも左端と上端を揃える。囲みは多用せず、見出しを本文に近づけ項目間を広く空けて余白でグループを分ける。タイトルと本文のジャンプ率を大きく。箇条書きは PowerPoint の機能でぶら下げインデント、間隔は段落の「間隔」で調整し、左揃えが基本。
- 追加日: 2026-10-22

## 伝わるデザイン「配色」
- URL: https://tsutawarudesign.com/miyasuku5.html
- 種類: 資料作成ガイド
- 参考にする点: 色は4色まで（背景・文字・メイン・強調）。背景は白、色を付けるなら灰色。PowerPoint の標準色は彩度が高すぎるので避け、強調色は最も重要な箇所だけに少量使う。
- 追加日: 2026-10-22

## Office for National Statistics「Creating PowerPoint presentations」
- URL: https://service-manual.ons.gov.uk/brand-guidelines/application/creating-powerpoint-presentations
- 種類: 官公庁の資料作成ガイド
- 参考にする点: テキストは左揃え、見出し・本文の位置を全スライドで揃える。1枚50語以下、余白で主な点を強調。柄のある背景・特殊効果・トランジションは避け、背景は薄い灰色。文字は最小18pt。
- 追加日: 2026-10-22

## Government Analysis Function「Data visualisation: colours」
- URL: https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-colours-in-charts/
- 種類: 官公庁のデータ可視化ガイド
- 参考にする点: 区別の必要が無いものは1色にし、意味の無い色を足さない。注目させたい1つだけを濃色、他は薄い灰色（focus palette）。背景は白、コントラストは4.5:1以上。
- 追加日: 2026-10-22

## GDS blog「Giving clear presentations」
- URL: https://gds.blog.gov.uk/2016/04/07/giving-clear-presentations/
- 種類: 官公庁の公開記事（自組織のプレゼン方針）
- 参考にする点: スライドには短い1行の文、見出しスライドはさらに語を減らす。比喩的なイメージ画像は使わず実物（画面・デモ）を見せる。テンプレートは意図的に簡素。
- 追加日: 2026-10-22

## Microsoft「Make your PowerPoint presentations accessible to people with disabilities」

- 追加日: 2026-10-22
