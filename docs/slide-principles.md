# スライドの方針

資料（PowerPoint）で守るルール。/pptx-review で採用した修正方針がここに蓄積される。
新しい資料を作るときも、このファイルに従うこと。

- ルールは「何をどうするか」を一行で書く（例: 本文スライドのタイトルは左揃えで、言いたいことを1文で書く）。
- 各ルールの末尾に由来を `（<ファイル名> <YYYY-MM-DD>）` の形で付ける。
- 例外を作るときは、ルールを消さずに例外として追記する。

## 配色と背景

- 本文スライドの背景はマスターで白（または薄い灰色）の単色にし、濃い単色の背景は表紙と章扉だけでスライド側で指定する（sample.pptx 2026-10-22）

## 図形と区切り

- 同じ種類の項目の並びは箱で囲まずに余白で区切り、箱は他と区別すべき1つの塊（結論・注意）にだけ使う。影とグラデーションの塗りは使わない（sample.pptx 2026-10-22）
- 数字を並べるときは、言いたい1つだけを大きくしてアクセント色を使い、他は小さく濃い灰色で従える（sample.pptx 2026-10-22）

## アイコンと絵文字

- タイトルと本文に絵文字を使わず、見出しの意味を繰り返すだけのアイコンは置かない（sample.pptx 2026-10-22）

## レイアウトと揃え

- 本文スライドのタイトルと本文は左揃えにして左端を揃え、タイトルは言いたいことの1文にする。箇条書きは段落の箇条書き設定を使う（sample.pptx 2026-10-22）
- タイトルは組み込みのタイトルのプレースホルダーに入れ、マスターとレイアウトの位置をスライドの本文と同じ左右の端に揃える（sample.pptx 2026-10-22）
- テーマの和文フォントを指定し（BIZ UDゴシック）、文字には日本語の指定を付ける（sample.pptx 2026-10-22）

## 文章

- 「革新的」「シームレス」「次世代」などの強調語と、「〜を実現」「今ここに」などの定型句は使わず、対象と事実だけを書く（sample.pptx 2026-10-22）
- 数字には出典（調査名・時期）を添える。出典が無い数字は作らず、記入欄を置いて確認する（sample.pptx 2026-10-22）

## 例外

- 表紙のタイトルは中央寄せのままでよい（sample.pptx 2026-10-22）
